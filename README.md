# Migración ACS a Next.js (Trabajo en equipo)

Este repositorio contiene la versión migrada del sitio ACS a Next.js 13+ usando App Router. Esta versión fue desarrollada en colaboración, y refleja nuestra propuesta estructural moderna del frontend del sitio.

## 🔧 Contribuciones personales
- Estructura de carpetas y layout general en `app/`
- Componentes: `SponsorsCarousel`, `HeroSection`, `Header`, etc.
- Uso de `use client` y modularización de secciones

## 🧩 Tecnología
Next.js · React · JavaScript · Git

Repositorio base: [JoxAQC/ACS-IT-Area](https://github.com/JoxAQC/ACS-IT-Area)
