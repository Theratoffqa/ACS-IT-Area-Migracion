# Migración ACS a Next.js (Trabajo en equipo)

Este repositorio contiene la versión migrada del sitio ACS a Next.js 13+ usando App Router. Esta versión fue desarrollada en colaboración, y refleja nuestra propuesta estructural moderna del frontend del sitio.

## 🔧 Contribuciones personales
- Estructura de carpetas y layout general en `app/`
- Implementación del layout general (`app/layout.js`) y rutas base (`app/page.js`).
- Creación de componentes reutilizables: `SponsorsCarousel`, `HeroSection`, `Header`, entre otros.
- Migración de las siguientes páginas/secciones:

  - `/about` – Nosotros
  - `/chapters` – Chapter officers
  - `/contact` – Contacto
  - `/events` – Eventos
  - Página de inicio (`/`) – Estructura del hero, carousel y secciones principales
- Uso de `use client` y modularización de secciones
- Implementación de reCAPTCHA para `/contact`
  
## 🧩 Tecnologías
Next.js · React · JavaScript · Git · CSS
